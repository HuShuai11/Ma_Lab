# 马乐课题组网站管理员使用说明

## 日常更新内容

1. 打开网站地址，在页脚点击“管理”，或直接访问 `/admin`。
2. 使用负责人分配的用户名和密码登录。
3. 在左侧选择“项目成果、团队成员、论文成果、科研动态、研究方向”或“网站设置”。
4. 点击“新增内容”，或在已有内容右侧点击“编辑”。
5. 填写信息；需要图片时，在“项目封面、成员照片、活动图片”处选择本地图片上传。
6. 选择“公开显示”后点击“保存并更新网站”。
7. 打开公开主页刷新一次，确认显示效果。

保存后内容已经在统一云端生效，其他管理员和访客不需要下载新文件。

## 两人同时编辑时怎么办

如果另一位管理员在你编辑期间已经保存了相同内容，系统会提示该内容已更新。此时：

1. 刷新页面。
2. 打开最新版本，确认对方修改。
3. 在最新版本上补充自己的内容并保存。

这样可以避免后保存的人覆盖前一位管理员的内容。

## 负责人如何管理账号

负责人登录后，在“管理员”模块中可以：

- 为新同学创建用户名、显示名称和初始密码。
- 把编辑提升为负责人，或把负责人调整为编辑。
- 停用毕业或不再负责维护的同学账号。
- 为忘记密码的同学重设密码。

不要共用同一个管理员账号。独立账号可以保留修改记录，也能在成员离开后单独停用。

## 内容状态说明

- **公开**：立即显示在公开网站。
- **隐藏**：内容仍然保留在后台，但访客看不到。
- **已删除**：内容进入回收状态；负责人或编辑可以选择“恢复”重新公开。

## 安全建议

- 初始密码和每位管理员的密码都应至少10位，建议包含字母、数字和符号。
- 不要在微信群或文档中长期发送密码。
- 每学期检查一次管理员名单，及时停用离组账号。
- 若怀疑密码泄露，负责人应立即在后台重设该账号密码；原有登录状态会失效。
