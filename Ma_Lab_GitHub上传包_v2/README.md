# 马乐课题组网站

东北电力大学自动化工程学院马乐课题组的公开展示网站与共享内容管理后台。

## 使用方式

- 访客访问公开网站，查看课题组介绍、项目、成员、论文和科研动态。
- 管理员访问 `/admin`，使用课题组分配的用户名和密码登录。
- 内容保存到统一的云端数据库；一位管理员发布后，其他人刷新页面即可看到最新内容。
- 上传的项目封面、成员照片和活动图片保存到统一的云端图片库。

日常更新内容不需要重新部署网站，也不需要把数据库文件发给其他同学。

## 管理员权限

- **负责人**：创建和停用账号、重设密码、调整负责人/编辑权限、查看全部修改记录。
- **编辑**：维护项目、成员、论文、研究方向、动态和首页文案。

系统会记录新增、修改、删除、上传和登录操作。两个人同时修改同一条内容时，后提交的人会收到提示，避免悄悄覆盖前一位同学的修改。

## 首次初始化

首次部署前，在站点的运行环境中设置以下变量：

```text
INITIAL_ADMIN_USERNAME=负责人用户名
INITIAL_ADMIN_PASSWORD=不少于10位的初始密码
INITIAL_ADMIN_DISPLAY_NAME=负责人显示名称
```

第一位负责人使用这组账号密码登录后，系统会自动创建负责人账号。之后可以在“管理员”模块中为其他同学创建独立账号；初始变量不再用于创建新账号。

请不要把真实密码写入 GitHub，也不要提交 `.env.local`。

## 本地预览（Windows）

需要 Node.js 22 或更高版本。首次运行：

```powershell
npm install
npm run dev
```

本地预览适合开发和检查页面样式。日常内容维护建议直接使用已经发布的网站后台，这样所有同学操作的是同一份云端数据。

## 代码、数据与发布

- **GitHub**：保存网站代码、数据库结构和部署说明。
- **D1**：保存网站文字内容、管理员账号、会话和操作记录。
- **R2**：保存上传图片和文件。
- **公开网站**：读取同一份 D1/R2 数据，因此管理员更新后无需重新发布代码。

修改程序代码时，运行以下命令确认构建无误：

```powershell
npm run db:generate  # 仅在修改 db/schema.ts 后需要
npm run build
```

数据库结构变更会生成 `drizzle/` 中的迁移文件；发布时必须一并带上。

## 课题组长期部署（推荐）

当前在线链接可用于演示。若要让课题组长期独立使用，建议将本项目放到课题组自己的 GitHub 私有仓库，并部署到课题组自己的 Cloudflare 账号：

- 一个网站同时提供公开主页 `/` 和管理中心 `/admin`，不需要维护两套网站。
- Cloudflare D1 保存内容、管理员和操作记录；R2 保存上传图片。
- 日常维护内容直接在管理中心完成，不需要重新部署。
- 修改程序代码后，合并到 GitHub 的 `main` 分支即可由 Cloudflare 自动发布。

首次部署及后续备份请参阅 [Cloudflare免费部署说明](docs/Cloudflare免费部署说明.md)。正式账号密码只在 Cloudflare 的机密变量中保存，绝不提交到 GitHub。
